# Лабораторна робота: Страхування

##  Реалізація предметної області (Варіант 11)
Відповідно до завдання варіанту "Страхування", у проєкті реалізовано наступну бізнес-логіку:
* **Визначено ієрархію страхових зобов'язань:** Створено базовий абстрактний клас та його конкретні реалізації (види страхування).
* **Сформовано дериватив:** Створено клас-сервіс, який агрегує набір страхових зобов'язань у єдиний дериватив.
* **Підрахунок вартості:** Реалізовано метод для обчислення загальної вартості всіх зобов'язань у деривативі.
* **Сортування:** Реалізовано сортування зобов'язань у деривативі на основі зменшення ступеня ризику.
* **Пошук за параметрами:** Додано функціонал пошуку зобов'язань, які відповідають заданому діапазону (за рівнем ризику).

##  Виконання технічних вимог
Додаток повністю відповідає поставленим вимогам до розробки:
1. **Використання ООП:** У коді активно застосовуються класи, інкапсуляція (приватні поля та гетери), успадкування (для видів страхування) та поліморфізм.
2. **Змістовність:** Кожен клас має логічну назву, що відповідає його ролі, та містить інформативне наповнення.
3. **Доцільне успадкування:** Успадкування застосовано лише там, де це має сенс (від базового зобов'язання до конкретних типів страхування).
4. **Java Code Convention:** Код оформлено з дотриманням офіційних стандартів програмування на Java.
5. **Розподіл по пакетах:** Усі класи коректно структуровані та розподілені по логічних Java-пакетах (`ua.knu.insurance.model`, `ua.knu.insurance.service`, `ua.knu.insurance.main`).
6. **Мінімалістична консоль:** Робота з консоллю зведена до мінімуму — програма автоматично ініціалізує дані, виконує обчислення та виводить результат.
7. **Тестування (JUnit 5 + Mockito):** Весь основний код повністю покрито Unit-тестами за допомогою фреймворку JUnit 5 та mock-об'єктів бібліотеки Mockito.
8. **Git та віддалений репозиторій:** Код розміщено на віддаленому репозиторії. Проєкт містить правильно налаштований файл `.gitignore`, а історія змін ведеться за допомогою логічних commit-повідомлень.
